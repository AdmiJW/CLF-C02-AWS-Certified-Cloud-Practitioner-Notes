# 1 - AWS Engagement Model

## **1.1 AWS Engagement Model**

The **AWS Engagement Model** describes the different ways customers can engage with AWS to obtain technical support, architectural guidance, and professional assistance in building and managing cloud solutions.

Customers can choose to develop internal AWS expertise or engage external professionals depending on their skills, requirements, and resources.

## **1.2 Ways to Engage with AWS**

### **Self-Service**

Customers build their own internal teams with AWS skills to:
- Design and develop solutions using AWS services.
- Deploy applications into production.
- Maintain and manage their applications independently.

### **AWS Support**

**AWS Support** provides technical assistance to customers experiencing issues with AWS services.
- The level of assistance and response time depend on the customer's AWS Support plan.
- Enterprise Support and Unified Operations include a designated **Technical Account Manager (TAM)**. See [AWS Support Plans](./26%20-%20AWS%20Support.md).

### **AWS Account Team**

AWS may provide an account team to manage its relationship with customers, particularly larger organizations.

The account team typically includes:

| Role                        | Responsibility                                                                            |
| --------------------------- | ----------------------------------------------------------------------------------------- |
| **AWS Account Manager**     | Manages customer relationships and provides commercial and pricing guidance.              |
| **AWS Solutions Architect** | Provides architectural guidance, solution design advice, and AWS service recommendations. |

The account team serves as a point of contact when customers are planning new solutions on AWS.

### **AWS Professional Services**

**AWS Professional Services (AWS ProServe)** is a team of skilled professionals within AWS that helps customers design, develop, and implement cloud solutions.
- Provides direct access to AWS expertise. 
- Helps customers build solutions on AWS.
- Engaged through professional service agreements.

### **AWS Partner Network (APN)**

The **AWS Partner Network (APN)** is a network of third-party organizations that provide AWS-related expertise, solutions, and services.

| Partner Type           | Purpose                                                             |
| ---------------------- | ------------------------------------------------------------------- |
| **Consulting Partner** | Helps customers design, build, deploy, and manage solutions on AWS. |
| **Technology Partner** | Provides technology solutions that support or integrate with AWS.   |

Customers requiring external assistance with solution development or production management can engage an APN Consulting Partner.

Customers can also engage companies outside the APN, but their AWS expertise is not recognized through APN membership.

## **1.3 AWS Engagement Options Comparison**

| Engagement Option                   | Primary Purpose                                                             |
| ----------------------------------- | --------------------------------------------------------------------------- |
| **Self-Service**                    | Build and manage solutions using internal expertise.                        |
| **AWS Support**                     | Obtain technical assistance with AWS-related issues.                        |
| **Technical Account Manager (TAM)** | Provide ongoing technical guidance and support.                             |
| **AWS Account Manager**             | Manage customer relationships and commercial guidance.                      |
| **AWS Solutions Architect**         | Provide architectural and service selection guidance.                       |
| **AWS Professional Services**       | Obtain hands-on consulting and implementation assistance directly from AWS. |
| **AWS Partner Network (APN)**       | Obtain solutions and professional assistance from AWS partners.             |

### **AWS Professional Services vs. AWS Partner Network**

The key distinction is **who provides the professional assistance**:
- **AWS Professional Services** - Professionals within AWS.
- **AWS Partner Network** - External organizations participating in the AWS partner ecosystem.

## **1.4 Exam Focus**

- **Technical assistance with AWS services - AWS Support**
- **Dedicated technical guidance - Technical Account Manager (TAM)**
- **Customer relationships and commercial guidance - AWS Account Manager**
- **Architecture and service selection advice - AWS Solutions Architect**
- **Professional consulting and implementation directly from AWS - AWS Professional Services**
- **Third-party AWS expertise and solutions - AWS Partner Network (APN)**
- **External assistance to design, build, and manage AWS solutions - APN Consulting Partner**

# 2 - AWS Professional Services

## **2.1 AWS Professional Services**

**AWS Professional Services (AWS ProServe)** is a global team of AWS experts that helps customers design, develop, and implement solutions on AWS.
- Consists of **AWS employees**.
- Available through short-term contractual engagements.
- Helps customers build new cloud solutions.
- Typically used by large enterprises requiring direct AWS expertise.

## **2.2 AWS IQ**

**Historical lecture context:** AWS IQ connected customers with certified freelancers and consulting firms. AWS shut it down in 2026. [AWS service shutdown status](https://docs.aws.amazon.com/general/latest/gr/full_shutdown_services.html)

## **2.3 AWS Managed Services (AMS)**

**AWS Managed Services (AMS)** helps customers operate their AWS environments securely and follow AWS operational best practices.

It combines AWS tools, services, and professional expertise to help customers:
- Manage ongoing cloud operations.
- Adopt AWS best practices.
- Operate securely within AWS environments.

The primary focus of AMS is **ongoing operations rather than building new solutions**.

## **2.4 AWS Professional Services vs. AWS IQ vs. AWS Managed Services**

Use **AWS Professional Services** for a scoped transformation or implementation engagement with AWS experts. **AWS Managed Services** helps run day-to-day cloud operations and appears here as lecture context. AWS IQ was a freelancer marketplace and is retired.

## **2.5 Exam Focus**

- **Build cloud solutions using AWS employees - AWS Professional Services**
- **Historical lecture reference** — AWS IQ previously connected customers with certified freelancers.
- **Manage ongoing AWS cloud operations - AWS Managed Services (AMS)**
- **Adopt operational and security best practices - AWS Managed Services (AMS)**
- **Implementation engagement with AWS experts** — AWS Professional Services.
- **Operational management - AWS Managed Services (AMS)**

# 3 - AWS Partner Network (APN)

## **3.1 AWS Partner Network (APN)**

The **AWS Partner Network (APN)** is a global network of third-party companies that provide AWS-related expertise, solutions, and professional services.
- Companies must meet AWS requirements to qualify for APN partnership.
- Customers can select partners based on their expertise, specialization, and partnership tier.
- Provides an alternative to engaging AWS Professional Services directly.

## **3.2 AWS Partner Types**

| Need | AWS Partner type |
| --- | --- |
| Design, migrate, or integrate a solution for a customer | **Systems integrator** or other AWS Services Partner. The lecture calls many of these consulting partners. |
| Build and sell a product that runs on or integrates with AWS | **Independent software vendor (ISV)** or other AWS Software Partner. The lecture uses technology partner. |
| Deliver authorized training | **AWS Training Partner**. |

Partner benefits include training and certification support, events, and program-specific commercial benefits such as eligible discounts. [Work with AWS Partners](https://aws.amazon.com/partners/work-with-partners/) · [AWS Partner Network](https://aws.amazon.com/partners/)

## **3.3 AWS Competency Program**

The **AWS Competency Program** recognizes AWS partners with specialized expertise in specific industries, workloads, and technology areas.

Examples of competencies include:
- Automotive
- Healthcare
- Financial Services
- Serverless

The program helps customers identify partners with the appropriate expertise for their specific business or technical requirements.

## **3.4 AWS Partner Tiers**

AWS partnership tiers reflect different levels of partner maturity and capabilities.

The progression described in the lecture is:

|Level|Classification|
|---|---|
|1|Registered|
|2|Select|
|3|Advanced|
|4|Premier|

Customers can consider both **partner competency** and **partnership tier** when selecting an AWS partner.
- **Competency** - Area of specialized expertise.
- **Tier** - Level of partnership maturity.

## **3.5 Exam Focus**

- **Find third-party companies with AWS expertise - AWS Partner Network (APN)**
- **Design, build, and manage customer solutions - AWS Consulting Partner**
- **Provide software and technology products that integrate with AWS - AWS Technology Partner**
- **Instructor-led AWS training - AWS Training Partner**
- **Identify partners with specialized industry or technical expertise - AWS Competency Program**
- **Partner maturity - Select, Advanced, and Premier tiers**
- **AWS employees - AWS Professional Services**
- **Third-party organizations - AWS Partner Network (APN)**

## 3.6 AWS Marketplace

**AWS Marketplace** lets customers discover, buy, and deploy third-party software or procure services from sellers. A buyer can review offers and manage subscriptions, use a negotiated **private offer**, and manage licenses or entitlements for eligible products across accounts. A **Private Marketplace** can constrain which products are approved for procurement.

**Exam cue:** Find a partner to design or deliver the project through **APN**. Buy its eligible software or services through **AWS Marketplace**. [AWS Marketplace Buyer Guide](https://docs.aws.amazon.com/marketplace/latest/buyerguide/)

# 4 - AWS Training and Certification

## **4.1 AWS Training and Certification**

**AWS Training and Certification** helps individuals and organizations develop AWS cloud skills through training programs, hands-on learning, and professional certifications.

## **4.2 AWS Training Options**

### **AWS Digital Training**

Provides online, self-paced learning resources to help individuals develop AWS knowledge and practical skills.
- Free digital courses.
- Hands-on learning opportunities.
- Allows individuals to learn at their own pace.

### **AWS Classroom Training**

Provides **instructor-led training**, allowing participants to interact directly with AWS instructors.
- Suitable for organizations developing an AWS-skilled workforce.
- Enables participants to ask questions and receive direct guidance.
- Helps employees prepare for upcoming AWS projects.

### **AWS Skill Builder**

**AWS Skill Builder** is an online learning platform for developing AWS cloud skills.
- Provides digital training courses and hands-on labs.
- Offers subscription-based access to premium learning content.
- Organizations can subscribe to provide training resources to employees.

## **4.3 AWS Educational Programs**

### **AWS Educate**

**AWS Educate** helps new cloud learners develop foundational cloud computing knowledge and AWS skills.

It is primarily intended for individuals who are beginning their cloud learning journey.

### **AWS Academy**

**AWS Academy** collaborates with educational institutions to provide cloud computing education and prepare students for careers in the cloud.

### **Training Programs Comparison**

|Program|Primary Purpose|
|---|---|
|**AWS Digital Training**|Self-paced online learning.|
|**AWS Classroom Training**|Interactive, instructor-led training.|
|**AWS Skill Builder**|Digital courses, hands-on labs, and premium learning resources.|
|**AWS Educate**|Foundational cloud education for new cloud learners.|
|**AWS Academy**|Cloud education through educational institutions.|

## **4.4 AWS Certification**

**AWS Certification** validates an individual's AWS cloud knowledge and technical skills through certification examinations.
- Individuals earn certifications by passing the corresponding examinations.
- AWS certifications are generally valid for **three years** from the date of passing the exam.

## **4.5 Exam Focus**

- **Self-paced AWS learning - AWS Digital Training**
- **Instructor-led training - AWS Classroom Training**
- **Digital courses and subscription-based hands-on learning - AWS Skill Builder**
- **Foundational cloud skills for new learners - AWS Educate**
- **Prepare students for cloud careers through educational institutions - AWS Academy**
- **Validate AWS knowledge and skills - AWS Certification**
- **AWS certification validity - 3 years**

# 5 - AWS Community - re:post

## **5.1 AWS re:Post**

**AWS re:Post** is an expert-led AWS community platform where users can ask technical questions, share knowledge, and find solutions to AWS-related issues.

It provides:
- Community-driven questions and answers.
- Curated technical answers and articles.
- Access to the **AWS Knowledge Center**.
- Collaboration with AWS experts and community members.

AWS re:Post is similar to Stack Overflow but focuses specifically on AWS-related topics.

## **5.2 AWS re:Post Public vs. Private**

|Offering|Description|Pricing|
|---|---|---|
|**AWS re:Post**|Public community platform for sharing AWS knowledge and resolving technical questions.|Free|
|**AWS re:Post Private**|Private knowledge-sharing and collaboration platform for employees within an organization.|Paid|

**AWS re:Post Private** enables organizations to build an internal AWS community where employees can discuss technical issues and share knowledge privately.

**Lifecycle note:** AWS re:Post Private reaches end of service on **June 30, 2027**. Public AWS re:Post is the exam’s community Q&A resource. [re:Post Private end of support](https://docs.aws.amazon.com/repostprivate/latest/userguide/repost-private-end-of-support.html)

## **5.3 AWS Knowledge Center**

The **AWS Knowledge Center** provides official AWS articles containing answers to frequently asked technical questions and guidance for troubleshooting common AWS issues.

Examples include:
- Troubleshooting EC2 instance connectivity.
- Resolving common AWS service issues.
- Finding solutions to technical problems.

The key distinction is:
- **AWS re:Post** - Community-driven questions, answers, and collaboration.
- **AWS Knowledge Center** - Official AWS troubleshooting articles and solutions.

**AWS Prescriptive Guidance** publishes playbooks, patterns, strategies, and implementation guidance. Use it to plan a migration or apply a proven approach. Use **Knowledge Center** for a scoped support answer and **re:Post** to ask a community question. [AWS Prescriptive Guidance](https://aws.amazon.com/prescriptive-guidance/)

## **5.4 Exam Focus**

- **Ask technical questions and collaborate with the AWS community - AWS re:Post**
- **Free public AWS knowledge-sharing platform - AWS re:Post**
- **Private AWS knowledge-sharing platform within an organization - AWS re:Post Private**
- **Official answers to common technical questions and troubleshooting guidance - AWS Knowledge Center**
- **Community-based technical assistance - AWS re:Post**
- **Direct technical assistance from AWS based on a support plan - AWS Support**
