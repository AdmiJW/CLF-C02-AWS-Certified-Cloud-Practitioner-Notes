## **1.1 AWS Certified Cloud Practitioner Exam Structure**

| Exam Detail           | Description                           |
| --------------------- | ------------------------------------- |
| Certification         | AWS Certified Cloud Practitioner      |
| Exam code             | **CLF-C02**                           |
| Total questions       | 65                                    |
| Scored questions      | 50                                    |
| Unscored questions    | 15                                    |
| Exam duration         | 90 minutes                            |
| Score range           | 100–1,000                             |
| Minimum passing score | **700**                               |
| Question types        | Multiple choice and multiple response |

**Unscored questions** are used by AWS to evaluate and improve future exams. Candidates cannot distinguish scored questions from unscored questions.

The passing score of 700 is a **scaled score**, not necessarily equivalent to answering 70% of the questions correctly.

### **Question Types**

| Question Type         | Description                                        |
| --------------------- | -------------------------------------------------- |
| **Multiple choice**   | Select one correct answer.                         |
| **Multiple response** | Select two or more correct answers, as instructed. |

Pay particular attention to the number of answers required for multiple response questions.

## **1.2 Exam Preparation**

Before taking the exam:
- Attempt the official AWS sample exam questions.
- Complete a full-length practice exam.
- Review incorrect answers and identify knowledge gaps.
- Revise the summary slides from each course section.
- Focus on distinguishing AWS services with similar purposes.

## **1.3 Exam Question Strategy**

- Spend approximately **one minute per question** during the first pass.
- If uncertain between answers, select the most likely answer and **mark the question for review**.
- If unfamiliar with a question, make an educated guess and mark it for review.
- Do not panic when encountering unfamiliar concepts, as some questions may be unscored.
- Pay attention to the number of answers required.
- **Do not leave any question unanswered.**

### **Time Management**

|Phase|Recommended Time|Objective|
|---|---|---|
|First pass|Approximately 60 minutes|Attempt all 65 questions|
|Review|Final 15–30 minutes|Revisit flagged questions and double-check answers|

Avoid spending excessive time on a single difficult question.

## **1.4 Exam Accommodation (ESL +30)**

**English as a Second Language (ESL +30)** is an exam accommodation available to eligible non-native English speakers.

It provides an additional **30 minutes** for AWS certification exams.

|Exam Duration|Time|
|---|---|
|Standard duration|90 minutes|
|Additional accommodation|30 minutes|
|Total duration with ESL +30|**120 minutes**|

### **Requesting ESL +30**

1. Log in to the AWS Certification Portal.
2. Navigate to **Exam Accommodations**.
3. Request the **ESL +30** accommodation.
4. Obtain approval before scheduling the exam.

According to the course, approval is generally immediate, and the accommodation applies to subsequent AWS certification exams.

## **1.5 Scheduling the Exam**

Schedule the exam through the **AWS Certification Portal**.
1. Select the Foundational-level AWS Certified Cloud Practitioner (CLF-C02) exam.
2. Proceed to **Pearson VUE**.
3. Select the preferred examination method.
4. Choose an appointment and complete payment.

### **Examination Methods**

|Method|Description|
|---|---|
|**Online proctored exam**|Take the exam remotely.|
|**Test center**|Take the exam at a physical testing location.|

Request any required exam accommodation before scheduling the exam.

## **1.6 AWS Certification Benefits**

After successfully passing an AWS certification exam, candidates receive a **50% discount** benefit for their next AWS certification exam.
- Available under Benefits in the AWS Certification Portal.
- Provided as a voucher code.
- Applied when paying for the next certification exam.

Remember to utilize this benefit when pursuing another AWS certification.
